URL routes - 
1. GET  - /auth/me - Validates token for protected route entry
2. POST - /auth/signin - signin route
3. POST - /auth/signup - signup route
4. GET  - /user/me - Gets user profile 
5. POST - /message/ - post message with body { content:"message",reciever:"id" }
6. GET  - /message/:threadId - get all the message associated with the thread
